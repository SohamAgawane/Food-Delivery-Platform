# 🍔 MealMap — Food Ordering Web App

MealMap is a modern food ordering web application built using React. It allows users to browse restaurants, explore menus, search for food, and add items to cart — just like a real-world food delivery platform.

The project focuses on building a scalable React application with clean architecture, reusable components, API integration, and performance optimization.

---

## 🚀 Features

* Browse restaurants
* Search restaurants and food items
* Filter restaurants based on ratings
* View restaurant menu
* Add items to cart
* Remove items from cart
* Shimmer UI for loading state
* Responsive design
* Optimized performance
* Lazy loading (code splitting)
* Error handling
* Custom hooks
* Reusable components
* Routing using React Router

## ⚙️ Installation & Setup

1. Clone the repository

```
git clone https://github.com/your-username/mealmap.git
```

2. Go to project folder

```
cd mealmap
```

3. Install dependencies

```
npm install
```

4. Start the development server

```
npm start
```
